# mqorderd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go daemon, `mqorderd`, that reads circuit orders from an IBM MQ queue and feeds them to the unchanged `orderprint` the same way lterm does, without losing orders.

**Architecture:**
- **Pure-Go core, unit-tested without MQ:**
  - `pages` splits a message into pages and classifies them using lterm's rules
  - `spool` writes page files with lterm's names
  - `journal` covers the crash window
  - `proc` is the per-message state machine, behind `Queue`/`Runner` interfaces
- **Thin cgo adapter** (`mqconn`) implements `Queue` with mq-golang.
- **`main`** adds the reconnect loop, signals, and `--check`.
- **Packaging:** systemd template unit, started and stopped by boot_nms when a YAML file exists. Built only in the 64-bit nmake pass.

**Tech Stack:**
- Go 1.24.1 (`/opt/devtools/bin/go`)
- `github.com/ibm-messaging/mq-golang/v5` **v5.7.3** (cgo)
- `gopkg.in/yaml.v3` v3.0.1, vendored
- IBM MQ 9.1.0.7 client (`/opt/devtools/mqm/v9.1.0-7`)
- Lucent nmake, systemd, ksh/sh (boot_nms)

**Spec:** `~/WorkNotes/plans/2026-10-14-5726-mqorderd-design.md`. Read it before starting any task.

## Global Constraints

- Source root: `cnc/mqorder/src/`, Go module path `netflex/mqorder`. The binary goes to `$(PBIN)/mqorderd` and installs to `/usr/cnc/bin/mqorderd`.
- **64-bit only:** build when `$(L64_SETUP)` == "1"; the 32-bit pass is a no-op.
- Build env: `CGO_ENABLED=1 GOTOOLCHAIN=local GOFLAGS=-mod=vendor CGO_CFLAGS=-I$(MQ_ROOT)/inc CGO_LDFLAGS="-L$(MQ_ROOT)/lib64 -Wl,-rpath,/opt/mqm/lib64"`, with `MQ_ROOT=/opt/devtools/mqm/v9.1.0-7`.
- Every module is vendored and committed under `cnc/mqorder/src/vendor/`. The build must not touch the network.
- Runs as `cmm`. The unit **must not** set `NoNewPrivileges=` (orderprint is setuid root).
- orderprint command: `<orderprint> <printer> <path>`, via fork/exec, never a shell. Default orderprint is `/usr/cnc/bin/orderprint`.
- Page file name: `<prefix>.<printer>.0.<epoch>.<pid %06d>.<seq %02d>`.
  - prefix is `ckt` or `ocy`
  - `seq` starts at 1 and resets when the epoch second changes
- Default dirs:
  - orders: `/usr/cnc/orders/printer/<printer>`
  - failed: `/usr/cnc/orders/mqorderd/<printer>/failed`
  - junk: `/usr/cnc/orders/mqorderd/<printer>/junk`
  - journal: `/usr/cnc/orders/mqorderd/<printer>/journal`
- Config: `/usr/cnc/data/mqorderd/<printer>.yaml`. Trace: `/usr/cnc/trace/mqorderd.<printer>`.
- MQ get: `MQGMO_SYNCPOINT|MQGMO_WAIT|MQGMO_CONVERT|MQGMO_FAIL_IF_QUIESCING`, wait 30s. Never set `MQGMO_ACCEPT_TRUNCATED_MSG`.
- Reconnect backoff: 5s, doubling, capped at 60s, retrying forever, reset after a successful open. Throttle repeated identical errors: log the first, then one summary line per 10 minutes with a count.
- Backout-only failure pause: 5s, doubling, capped at 60s. `max_backout` defaults to 5.
- **Never** run orderprint twice on a page it has already been run on.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Any edit to a Makefile/.mk/.nmk must follow the `writing-nmake-makefiles` skill.

## Review Focus

1. **A message with CRLF line endings and no form-feeds.** Expect one page, with `\r` stripped and content otherwise byte-identical. Test: `TestSplit_CRLFNoFormFeed` (Task 2).
2. **The orders dir doesn't exist at first start** (fresh customer). Expect it to be created `0777` like lterm (`mkdir(dir,0777)`), not a crash loop. Test: `TestWriter_CreatesDir` (Task 3).
3. **A message larger than the initial get buffer** (multi-page orders can exceed 64 KiB). Expect the get to retry with a larger buffer, with no truncation or loss. Test: `TestGetGrowsBuffer` against a fake `rawGetter` (Task 6).
4. **orderprint moves the input file and then fails** (exit 2 after `movefile`). Expect the failed copy to come from `<orders.dir>/<basename>`, and no "file not found" crash. Test: `TestHandle_FailedPageMovedByOrderprint` (Task 5).
5. **SIGTERM while orderprint is running on page 2 of 4.** Expect the remaining pages to finish, then commit, then exit 0. Test: `TestRunLoop_StopFinishesMessage` (Task 7).

### Task 2: Page splitter and classifier (lterm rules)

**Files:**
- Create: `cnc/mqorder/src/internal/pages/pages.go`
- Test: `cnc/mqorder/src/internal/pages/pages_test.go`, `cnc/mqorder/src/testdata/` (synthetic fixtures)

**Interfaces:**
- Produces:
  ```go
  package pages
  type Kind int
  const (Junk Kind = iota; Ckt; Ocy)
  func (k Kind) Prefix() string          // "junk","ckt","ocy"
  func Split(msg []byte) [][]byte        // lterm processInput rules, per message
  func Classify(page []byte) Kind        // lterm writeOut rules
  ```

**Rules** (from `cnc/rcmd/src/lterm.c` ~300–445 and ~476–497; read that code):
- `\f` (0x0C) ends the current page. A form-feed before any page content emits nothing.
- `\r` is dropped. At each `\r`, if the page so far contains `CKT` or `SYS` **and** the page *starts with* `PG C<int>-<int>` with equal ints (C `sscanf` semantics: no leading-whitespace skip), set end-of-order. The next non-whitespace byte then starts a new page.
- **Deliberate deviation (my call; note it in a code comment):** lterm drops the byte that triggers the end-of-order split (`strcpy(rbuf,buf+ii+1)` skips `buf[ii]`). Split **keeps** that byte as the first byte of the next page, because dropping data contradicts "no order lost".
- At the end of the message, a remaining page holding any non-whitespace is emitted. Pages that are empty or only whitespace are never emitted.
- Classify:
  - `Ckt` if (`CKT` or `SYS`) and `" PG "` are present
  - otherwise `Ocy` if it contains `ORDERS COMPLETED YESTERDAY` or `ORDERS/CIRCUITS/SEGMENTS COMPLETED YESTERDAY`
  - otherwise `Junk`

- [ ] **Step 1: Write failing tests**
  - `TestSplit_FormFeeds`: `"\fA PG 1\fB PG 2\f"` gives `["A PG 1","B PG 2"]`.
  - `TestSplit_LeadingDataBeforeFirstFF`: `"A\fB"` gives `["A","B"]`.
  - `TestSplit_CRLFNoFormFeed` (Review Focus 1): `"CKT X PG 1\r\nline2\r\n"` gives one page, `"CKT X PG 1\nline2\n"`.
  - `TestSplit_EndOfOrderWithoutFF`: `"PG C2-2 CKT\r\n  \nNEXT"` gives `["PG C2-2 CKT\n  \n","NEXT"]`. The `N` is kept (the deviation).
  - `TestSplit_EndOfOrderNotAtStart`: `"xx PG C2-2 CKT\r\nNEXT"` gives a single page, matching lterm's start-anchored sscanf.
  - `TestSplit_WhitespaceOnlyDropped`: `"\f \n \f"` gives `[]`.
  - `TestClassify`: a table covering ckt via CKT, ckt via SYS, `"CKT"` without `" PG "` → Junk, both ocy strings → Ocy, and empty → Junk.

### Task 3: Spool writer (naming, ocy/keepjunk state)

**Files:**
- Create: `cnc/mqorder/src/internal/spool/spool.go`
- Test: `cnc/mqorder/src/internal/spool/spool_test.go`

**Interfaces:**
- Consumes: `pages.Kind`, `config.Orders`
- Produces:
  ```go
  package spool
  type Clock func() time.Time
  type Writer struct { /* dir, printer, pid, clock, seq state, lastFile, inOcy */ }
  func New(o config.Orders, printer string, pid int, clock Clock) *Writer
  // Write stores one page. runOrderprint=false means it was kept aside (junk) and
  // must not be handed to orderprint.
  func (w *Writer) Write(page []byte, k pages.Kind, msgID string, pageNo int) (path string, runOrderprint bool, err error)
  // KeepFailed copies a page that orderprint failed on into FailedDir as
  // <base(path)>.<msgID>.p<pageNo>. It reads from path, or from
  // <Orders.Dir>/<base(path)> if orderprint moved it. It returns the copy's path.
  func (w *Writer) KeepFailed(path, msgID string, pageNo int) (string, error)
  // KeepRaw writes a whole message to FailedDir as raw.<msgID> (poison/unprocessed).
  func (w *Writer) KeepRaw(data []byte, msgID string) (string, error)
  ```

**Behavior** (`lterm.c writeOut` ~448–530):
- Ckt/Ocy go to `<Dir>/<prefix>.<printer>.0.<epoch>.<pid %06d>.<seq %02d>` with `runOrderprint=true`. An Ocy page sets `inOcy`. The file is opened `O_CREAT|O_WRONLY|O_APPEND, 0666`, written, `fsync`ed and closed.
- Junk with `KeepJunk=false` (the default): write to `<JunkDir>/junk.<printer>.<msgID>.p<pageNo>` with `runOrderprint=false`.
- Junk with `KeepJunk=true`:
  - if `inOcy`, append to `lastFile`'s name with `runOrderprint=true` (lterm behavior)
  - otherwise write `<Dir>/junk.<printer>.0.<pid %06d>.<seq %02d>` with `runOrderprint=false`
- `CaptureOnly` is handled by `proc`, not here.
- Create directories on demand with `MkdirAll(dir, 0777)`.

### Task 5: Message processor (state machine)

**Files:**
- Create: `cnc/mqorder/src/internal/proc/proc.go`, `cnc/mqorder/src/internal/proc/runner.go`
- Test: `cnc/mqorder/src/internal/proc/proc_test.go`

**Interfaces:**
- Consumes: `pages.Split/Classify`, `spool.Writer`, `journal.Journal`, `config.Config`
- Produces:
  ```go
  package proc
  type Message struct { MsgID []byte; Data []byte; BackoutCount int32 }
  func (m *Message) ID() string                 // hex of MsgID
  var ErrNoMessage = errors.New("no message")
  type Queue interface {
      Get(wait time.Duration) (*Message, error)   // ErrNoMessage on timeout
      Commit() error
      Backout() error
      PutBackout(m *Message) error                // put to backout queue inside current UOW; nil-op if none configured
  }
  type Runner interface {
      // Run runs orderprint. execErr != nil means it could not be started at all.
      Run(printer, path string) (exitCode int, execErr error)
  }
  type ExecRunner struct{ Path string }          // fork/exec, no shell; signal → exitCode 128+sig
  type Logger interface { Printf(level int, format string, a ...any) }
  type Outcome int
  const (Committed Outcome = iota; BackedOut)
  type Processor struct {
      Cfg *config.Config; Q Queue; R Runner; J *journal.Journal; W *spool.Writer; Log Logger
  }
  func (p *Processor) Handle(m *Message) (Outcome, error) // error only for Commit/Backout failures
  ```

**Algorithm** (spec, "Message processing"):
1. If `BackoutCount >= Cfg.MQ.MaxBackout`: `KeepRaw`, `PutBackout`, `Commit`, error trace → Committed.
2. `st := J.Load()`. If `st.MsgID == m.ID()`: skip the pages in `st.Started`. The highest started page has an unknown outcome, so `KeepFailed` it with an error trace. If `st.MsgID` is non-empty and different: trace "stale journal" and clear it.
3. `J.Begin(m.ID())` (unless resuming), then `Split`. For each page N (1-based) not skipped:
   - `Write`.
     - On a write error **before any page was handed over**: `J.Clear`, `Backout` → BackedOut.
     - On a write error after that: `KeepRaw` the whole message, trace, and stop processing pages (then commit).
   - If `!runOrderprint` or `CaptureOnly`: continue.
   - `J.MarkStarted(N)`, then `R.Run`.
     - `execErr != nil` with nothing handed over yet → `J.Clear`, `Backout` → BackedOut. (`MarkStarted` for this page is undone by the Clear.)
     - `execErr != nil` after something was handed over → `KeepFailed` this page plus the rest unprocessed, then commit.
     - exit 0 → `os.Remove(path)`, ignoring ENOENT.
     - non-zero → `KeepFailed(path)`, error trace with `"orderprint exit %d page %d/%d msg %s file %s"`, continue.
4. `Commit`, then `J.Clear` → Committed.

`CaptureOnly`: page files stay in `Orders.Dir`, nothing is journaled, then commit.

  package mqconn
  type Conn struct { /* ibmmq.MQQueueManager, queue, backout queue */ }
  func Dial(c config.MQ) (*Conn, error)                 // MQCONNX + MQOPEN(INPUT_SHARED|FAIL_IF_QUIESCING|INQUIRE)

  func (c *Conn) Commit() error
  func (c *Conn) Backout() error
  func (c *Conn) PutBackout(m *proc.Message) error      // MQPUT1 to BackoutQueue under SYNCPOINT
  func (c *Conn) Depth() (int32, error)                 // MQINQ CURDEPTH
  func (c *Conn) Close()                                 // MQCLOSE + MQDISC, never panics

  type rawGetter interface { Get(md *ibmmq.MQMD, gmo *ibmmq.MQGMO, buf []byte) (int, error) }

- `getGrowing` starts at 64 KiB. On `MQRC_TRUNCATED_MSG_FAILED` it grows to `max(2×, DataLength)` and retries.
- `MQRC_NO_MSG_AVAILABLE` maps to `proc.ErrNoMessage`.
- `IsConnectionError` is true for reason codes 2009, 2059, 2161, 2162, 2202, 2195, 2538, 2537, 2548, 2273, 2019 (HOBJ invalid after reconnect).
- Errors returned from Dial/Get/Commit wrap `*ibmmq.MQReturn`, so `Reason` works on them.

- Create: `cnc/mqorder/src/internal/trace/trace.go`, `cnc/mqorder/src/loop.go`, `cnc/mqorder/src/main.go`
- Test: `cnc/mqorder/src/internal/trace/trace_test.go`, `cnc/mqorder/src/loop_test.go`

**Interfaces:**
- Consumes: everything above
- Produces:
  ```go
  package trace
  func Open(path string, level int) (*Logger, error)    // append, "2006-01-02 15:04:05 " prefix
  func (l *Logger) Printf(level int, format string, a ...any)
  type Throttle struct { /* key, count, last */ }
  func (t *Throttle) Report(l *Logger, key string, now time.Time, format string, a ...any)
      // first occurrence of key logs; repeats log "<msg> (repeated N times)" at most every 10m; new key resets

  package main
  type dialFunc func() (proc.Queue, func(), error)          // queue, close, error
  type backoff struct{ cur time.Duration }                  // Next(): 5s→10s→…→60s; Reset()
  func runLoop(ctx context.Context, dial dialFunc, newProc func(proc.Queue) *proc.Processor,
               log *trace.Logger, sleep func(context.Context, time.Duration)) error
  ```

**Run loop:**
- Dial, retrying with backoff and throttling identical failures. Each failure log includes the reason code and name plus host/port/channel/qmgr/queue.
- Reset the backoff after the first success.
- Get with a 30s wait:
  - `ErrNoMessage` → loop
  - connection error → close, reconnect
  - otherwise → `Handle`, and after BackedOut use a separate backoff pause
- On `ctx.Done()`, checked only **between** messages: close and return nil.

**main.go flags:**
- `mqorderd <printer>`
- `-c <file>`
- `--check <printer>`: Dial, Depth, prints `OK depth=N` or `FAIL <code> <name>`, exit 0/1, no retries
- `-v`: prints `mqorderd ` + `debug.ReadBuildInfo` main version

**Startup:** load config. On error, print to stderr and exit 2; systemd restarts it after RestartSec. Open the trace at `/usr/cnc/trace/mqorderd.<printer>`. SIGTERM/SIGINT cancel ctx. SIGHUP is ignored.

  - `TestRunLoop_ReconnectsOnConnectionError`: fake dial fails twice with 2059, then succeeds. The fake queue returns a connection error once, then ErrNoMessage until ctx is cancelled. Assert dial is called 4 times, the sleeps are `[5s,10s,5s]`, and the trace contains `2059`.
